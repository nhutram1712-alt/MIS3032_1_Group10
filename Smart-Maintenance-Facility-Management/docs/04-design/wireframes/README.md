# Wireframes

Thư mục chứa file wireframe / mockup của các màn hình trong `../screen-list.md`.

## Quy ước đặt tên

`<mã-màn-hình>-<tên-màn-hình>-v<phiên-bản>.<đuôi>`

Ví dụ: `SCR-001-dashboard-v1.png`

## Ghi chú

- File nguồn (Figma, Draw.io...) để cùng thư mục hoặc ghi link vào đây.
- Mỗi lần cập nhật tăng số phiên bản, không ghi đè bản cũ.
